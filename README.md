## 🚀 Projects I've Shipped

### 🤖 [RAG-Based Research Paper Assistant](https://github.com/codercodes123)
> Query research papers in plain English. No more Ctrl+F through 40-page PDFs.

Built a full Retrieval-Augmented Generation pipeline from scratch —
PDF ingestion → chunking → embeddings (HuggingFace) → vector search (FAISS/ChromaDB) → 
contextual answers via Groq LLM + LangChain.

`Python` `LangChain` `HuggingFace` `FAISS` `ChromaDB` `Groq LLM`
